# Tested bytecode changes / Testowane poprawki bytecode

These are source inputs, not an installable APK. `jni-java-hook.diff` patches disassembled `AvrcpNativeInterface.smali`; `allow-target.diff` patches disassembled `btservice/Config.smali`; `NgdAvrcpLegacy.smali` is the added class in `com/android/bluetooth/avrcp/`. They preserve the exact tested bytecode changes independently of the equivalent Java export.

Work on a copy of the matching baseline APK. Disassemble `classes.dex` with baksmali, review/apply both diffs to the corresponding classes and add the shim. Assemble with smali. Also set the existing boolean `profile_supported_avrcp_target` to true in the APK resources without enabling other profile flags. The matching Java/resources/Soong source changes are in `src/android-app`. Build the separate ARM64 bridge against the retained extension headers, and package it as a native library next to the unchanged adapter JNI. Re-sign using an authorized matching platform certificate; the tested unit uses public AOSP test keys, which must not be assumed on other units. Verify signing and DEX before any deployment.

Reassembly, resource/signing tool versions or a full source rebuild can change APK hashes. Such a result is a new candidate requiring review and device testing. The assembler intentionally accepts only the exact recorded artifacts; it is not a way to approve arbitrary rebuilds. See [the integration guide](../../docs/AVRCP.md) for the system-package path, supervisor pinning, component state, evidence and rollback requirements.

PL: Pliki zawierają dokładne zmiany smali testowanego APK, nie gotową aplikację. Na kopii zgodnego APK rozłóż DEX, zastosuj oba patche, dodaj klasę i złóż DEX ponownie. W zasobach włącz wyłącznie `profile_supported_avrcp_target`. Zbuduj osobny most ARM64; zachowaj główny JNI. Podpis musi odpowiadać legalnie dostępnym kluczom danej jednostki. Nowy wynik budowy wymaga własnego przeglądu i testu. Nie zmieniaj sum w instalatorze tylko po to, żeby zaakceptował inną kompilację. Szczegóły w instrukcji PL/EN powyżej.
